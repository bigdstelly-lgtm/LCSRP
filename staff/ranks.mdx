Our server is moderated by a tiered staff team with clearly defined permissions at each level. Understanding who can do what helps you know who to contact when something goes wrong — and what to expect from each rank.

## Staff Hierarchy

Staff ranks in ascending order of authority:

| Rank | In-Game Permission Level | Description |
|---|---|---|
| Moderator | Moderator | Front-line moderation; handles rule violations and player reports in real time |
| Administrator | Administrator | Elevated moderation; handles bans, admin commands, and complex disputes |
| Co-Owner | Co-Owner | Full server control; manages staff, server settings, and major decisions |
| Owner | Owner (reserved) | Server creator; has unconditional access and reserved join spot |

## What Each Rank Can Do

<AccordionGroup>
  <Accordion title="Moderator">
    Moderators are the first point of contact for player issues. They can:

    - Kill, heal, bring, and refresh players
    - Give or clear wanted levels
    - Jail players (5-minute duration)
    - Kick players from the server
    - Start and stop fires
    - Spectate players using `:view`
    - Display server-wide hints and messages
    - Set the time of day
    - Teleport to and between players
    - View kill logs, command logs, and bans
  </Accordion>
  <Accordion title="Administrator">
    Administrators have all Moderator permissions, plus:

    - Ban players from the server
    - Unban previously banned players
    - Grant or revoke Moderator permissions
    - Control weather (Premium Server required)
    - Activate Peace Time (Premium Server required)
    - Display priority countdown timers (Premium Server required)
  </Accordion>
  <Accordion title="Co-Owner">
    Co-Owners have all Administrator permissions, plus:

    - Full access to all server commands
    - Manage server settings and configuration
    - Grant or revoke Administrator permissions
    - Priority queue entry (front of queue when server is full)
  </Accordion>
  <Accordion title="Owner">
    The server owner has unrestricted access to all commands and settings. The owner always has a **reserved spot** on the server — they are never placed in the queue.
  </Accordion>
</AccordionGroup>

## Priority Queue

When the server is full, staff members receive queue priority:

- **Owner**: Reserved spot — always enters immediately
- **Co-Owner / Administrator**: Priority queue — moved to the front automatically
- **Moderator**: Priority queue — moved to the front automatically
- **Regular players**: Standard queue — wait in order

## Becoming a Staff Member

Staff positions on our server are by invitation or application through our community. If you are interested in joining the staff team, reach out through our Discord server. All staff members must:

- Be in good standing on the server (no active bans or recent kicks)
- Demonstrate knowledge of the server rules
- Be willing to moderate fairly and consistently
- Be available during scheduled server sessions

<Note>
Staff powers (Moderator/Administrator/Co-Owner) are granted in-game using the `:mod` and other permission commands. These permissions are server-specific and do not transfer to other private servers.
</Note>

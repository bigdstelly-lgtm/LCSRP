Our server owner can adjust a range of settings to shape the gameplay experience. This page explains what each setting does, how it affects your experience as a player, and which settings require a Premium Server upgrade.

<Note>
Only the **server owner** and designated staff can change server settings. Players cannot adjust server settings themselves.
</Note>

## Accessing Server Settings

Server settings are accessed from the **Private Server tab** in the in-game menu (the icon next to the main menu button). This is only visible to the server owner.

## Standard Settings

These settings are available on all private servers:

| Setting | Description |
|---|---|
| **Server Name** | The name displayed in the server list when players browse for servers |
| **Server Description** | A short description shown when a player selects your server |
| **Access** | Controls whether the server appears in the Listed Servers tab. When disabled, the server is unlisted and can only be joined by code or direct link |
| **Join Code** | A generated code players use to join the server via the "Join By Code" tab |
| **Max Players** | Sets the maximum number of players allowed. Maximum is 40. One spot is always reserved for the owner |
| **Team Balance** | Enables restrictions on how many players can join any one team at a time |
| **Wanted Command** | Allows all players to use `makewanted` to raise their own wanted level by 1 star |
| **Automatic NPC Calls** | Enables or disables AI-generated EMS call events |
| **Traffic Cameras Make You Wanted** | When enabled, traffic infractions (speeding, running red lights) will raise your wanted level |
| **Account Age Minimum** | If enabled, sets a minimum Roblox account age for joining the server |
| **Automatic Traffic Lights Breaking** | When enabled, traffic lights will randomly malfunction during sessions |
| **Automatic DOT Debris Calls** | Enables automatic road debris calls for DOT players to respond to |
| **Automatic Major Server Calls** | Enables large-scale incident calls that spawn across the map |
| **Automatic Fires** | When enabled, fires spawn randomly. When disabled, fires must be started manually using `:startfire` |
| **Server Link** | A shareable URL that places players directly into the server queue, even if the server is unlisted |
| **Devices Allowed** | Restricts or allows Mobile players, PC players, or both |
| **Account Verification Required** | When enabled, players must verify their Roblox account before joining |

## How Settings Affect Your Experience

<AccordionGroup>
  <Accordion title="Team Balance">
    When Team Balance is enabled, each team has a cap on how many players can join. If a team is full, you must choose another or wait. This prevents one team from dominating the server's population.
  </Accordion>
  <Accordion title="Automatic Fires">
    When Automatic Fires are on, fires will periodically break out across Liberty County without staff intervention. When disabled, fires only happen when a Moderator+ runs `:startfire` or `:startnearfire`. This gives staff more control over pacing.
  </Accordion>
  <Accordion title="Traffic Cameras">
    When Traffic Cameras make you wanted, driving recklessly — speeding, running red lights — will raise your wanted level automatically. This makes civilian driving more consequential and gives Law Enforcement more to respond to.
  </Accordion>
  <Accordion title="Account Restrictions">
    Account Age Minimum and Account Verification Required are both tools to reduce the chance of disruptive new accounts joining the server. If you have a newer account and are unable to join, contact server staff through Discord.
  </Accordion>
</AccordionGroup>

## Server Link vs. Join Code

| Method | Visibility | Queue Behaviour |
|---|---|---|
| **Server Link** | Works even on unlisted servers | Places player in queue via browser |
| **Join Code** | Works on unlisted servers | Player enters code in-game under "Join By Code" |
| **Listed Server** | Only works if server is set to Listed | Player clicks "Join Server" in the server list |

<Tip>
The **Server Link** is the most convenient join method for community members. Share it in your Discord server so players can join with one click without needing to remember the code.
</Tip>

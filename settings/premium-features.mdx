Upgrading your private server to **Premium** unlocks a set of powerful additional commands and settings that give server staff more control over the gameplay experience. The Premium upgrade costs **185 Robux** and is a one-time purchase per server.

<Note>
The standard private server creation fee is **50 Robux** (one-time). The Premium upgrade is an additional **185 Robux**. Both are one-time fees — there is no monthly subscription.
</Note>

## Premium Commands

These commands are only available on Premium Servers. They require **Administrator or Co-Owner** permission to use:

### Weather Control

```
:weather [Type]
```

Changes the server's weather. Available weather types:

| Type | Effect |
|---|---|
| `clear` | Clear skies, standard visibility |
| `rain` | Rainfall with reduced visibility |
| `thunderstorm` | Heavy storm with lightning |
| `fog` | Dense fog — significantly reduces visibility |

**Example:**
```
:weather thunderstorm
```

### Priority Timer

```
:prty [Seconds]
```

Displays a countdown timer to all players at the bottom-left of their screen, above the minimap. The timer signals that a priority event is in progress. During this time, civilian criminal activity is restricted.

**Example:**
```
:prty 300
```
This displays a 5-minute priority countdown to all players.

<Note>
The timer is measured in **seconds**. To calculate: multiply minutes by 60. For a 10-minute priority: `:prty 600`.
</Note>

### Peace Time

```
:pt [Seconds]
```

Activates Peace Time for the specified duration. During Peace Time:

- All PVP damage between players is **disabled**
- A countdown timer is shown on every player's screen
- Used during server startup or special events to prevent combat before roleplay is established

**Example:**
```
:pt 300
```
This activates 5 minutes of Peace Time with no PVP damage.

## When to Use Each Premium Feature

| Feature | Best Used When |
|---|---|
| `:weather rain` | Setting the atmosphere for a dramatic pursuit or large-scale incident |
| `:weather fog` | Creating a tense, low-visibility scenario |
| `:prty [Seconds]` | Announcing a major criminal event (bank robbery, hostage situation) |
| `:pt [Seconds]` | At server startup before players have loaded in and selected teams |
| `:weather clear` | Resetting weather after a controlled event |

## Upgrading to Premium

To upgrade your private server to Premium:

<Steps>
  <Step title="Open the Servers Menu">
    Click the menu icon (☰) and navigate to the **Servers** tab.
  </Step>
  <Step title="Go to Own Servers">
    Select **Own Servers** to see the servers you own.
  </Step>
  <Step title="Select Your Server">
    Click on the server you want to upgrade.
  </Step>
  <Step title="Click Upgrade to Premium">
    Select **Upgrade Premium** and confirm the purchase. The cost is **185 Robux** and is charged once.
  </Step>
</Steps>

<Tip>
Premium features dramatically improve session quality for high-population servers. If your server regularly runs priority events or structured sessions, the upgrade is highly recommended.
</Tip>

Our server is a private ER:LC server, meaning you need either a **server code** or a **direct link** to join. This page explains every method available and what to expect once you're in the queue.

## Before You Join

<Note>
  You must have a Roblox account to play ER:LC. If the server has an **Account Age Minimum** enabled, your account must meet the required age before you can enter.
</Note>

## Joining Methods

<Tabs>
  <Tab title="Via Server Code">
    <Steps>
      <Step title="Open the Servers Menu">
        Launch ER:LC on Roblox. Once in a server (or on the main screen), click the **menu icon** (☰) in the upper-right corner.
      </Step>
      <Step title="Go to the Servers Tab">
        In the menu, click the **Servers** tab at the top.
      </Step>
      <Step title="Click Join By Code">
        Select the **JOIN BY CODE** tab within the Servers menu.
      </Step>
      <Step title="Enter the Code">
        Type `LCSRPZ` into the **ENTER CODE** text box, then click **JOIN**.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Via Direct Link">
    <Steps>
      <Step title="Get the Server Link">
        Obtain the direct server link from our Discord server or from a staff member.
      </Step>
      <Step title="Open the Link in a Browser">
        Paste the link into your browser. Roblox will open and place you into the server queue automatically — even if the server is unlisted.
      </Step>
      <Step title="Wait for the Queue">
        If the server is full, you'll enter a queue. You'll join as soon as a spot opens.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Via Listed Servers">
    <Steps>
      <Step title="Open the Servers Menu">
        Click the **menu icon** (☰) in the upper-right corner and select the **Servers** tab.
      </Step>
      <Step title="Browse Listed Servers">
        If our server is currently set to **Listed**, it will appear under the **Listed Servers** tab. Click on the server name.
      </Step>
      <Step title="Click Join Server">
        After the server information appears on the right side of the screen, click **JOIN SERVER**.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Queue Priority

When the server is full, players are placed in a queue. Your position in that queue depends on your server role:

| Role | Queue Behaviour |
| --- | --- |
| Server Owner | Reserved spot — always guaranteed entry |
| Co-Owner / Administrator | Priority queue — moved to the front automatically |
| Moderator | Priority queue — moved to the front automatically |
| Regular Player | Standard queue — wait for a spot to open |

## Troubleshooting

<AccordionGroup>
  <Accordion title="I entered the code but it says it's invalid">
    Server codes can change. Make sure you're using the most recent code from our Discord server. Older codes may have expired.
  </Accordion>

  <Accordion title="The server isn't appearing in the listed servers list">
    The server may currently be set to **Unlisted**. Use the join code or direct link instead. Check our Discord for the latest access method.
  </Accordion>

  <Accordion title="I'm stuck in the queue for a long time">
    The server has a maximum of 40 players. If the queue is long, wait for players to leave. The server link method always places you in the queue automatically.
  </Accordion>

  <Accordion title="I was kicked on joining due to account age">
    Our server may have an **Account Age Minimum** enabled. Check the server description or our Discord for the minimum account age requirement.
  </Accordion>
</AccordionGroup>

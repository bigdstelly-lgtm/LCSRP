A **priority event** (or "priority") is a server-wide announcement that signals a major active incident — typically a serious crime like a hostage situation, armed standoff, or high-speed pursuit. When a priority is active, the entire server shifts focus to that event, and specific rules apply to all players.

## What Is a Priority?

A priority event is triggered by a staff member using the `:prty` command, which displays a countdown timer on every player's screen. The timer indicates how long the priority cooldown lasts.

```
:prty 300  → displays a 5-minute priority timer to all players
```

During a priority, the active incident takes precedence over all other roleplay on the server.

## Rules During an Active Priority

<Warning>
While a priority event is active, **you may not commit any criminal activity** that would raise your wanted level. This is a hard rule — violations will result in an immediate kick.
</Warning>

| Player Type | What to Do During a Priority |
|---|---|
| Law Enforcement | Respond to and manage the priority incident |
| Fire / EMS | Stage nearby and stand by for casualties |
| DOT | Clear the route to the incident if possible; hold otherwise |
| Civilian (uninvolved) | Stop all criminal activity; observe from a safe distance |
| Civilian (criminal) | Stand down immediately; do not escalate |

## The Priority Timer

The timer shown on-screen counts down the **cooldown period** — the minimum time between priority events. Once the timer expires:

- A new priority can be started if needed
- Criminal activity may resume (once the active incident is resolved)
- Staff will typically announce when normal play resumes

## Peace Time

Staff may activate **Peace Time** using the `:pt` command during special sessions or server startup. Peace Time:

- Prevents all PVP damage between players
- Displays a countdown timer on every player's screen
- Is used to give the server time to populate before active roleplay begins

```
:pt 300  → activates a 5-minute peace time where PVP damage is disabled
```

<Note>
Peace Time and the Priority Timer are different. Peace Time disables PVP; the Priority Timer signals an active incident and restricts criminal activity.
</Note>

## Requesting a Priority

If you are planning a major criminal scenario (e.g., hostage situation, bank robbery), you should:

1. Request staff approval **before** beginning the scenario
2. Wait for staff to activate the priority timer
3. Ensure all involved players are ready before the scenario starts

Do not self-initiate major scenarios without staff awareness. Doing so may be stopped mid-scene.
